# MineMAP

マインクラフト（Minecraft）の座標（X / Y / Z）を入力して2Dマップ上に可視化し、初期スポーン地点・拠点・村・ネザーゲートなどの重要スポットを管理できる、オフライン対応の非公式PWA地図アプリです。

---

- **MineMAP はマインクラフトの非公式ファンメイドアプリです。** Mojang Studios および Microsoft とは一切関係ありません（公式アプリではありません）。
- アプリ内に掲載している **鉱石のY座標ヒント、エンドラ討伐手順、構造物・イベントの攻略メモ、移動時間の目安** などの情報は、ゲームのバージョンアップやエディション（Java版 / 統合版）の違い、地形・状況によって変わる場合があります。
- 掲載情報の正確性や最新性についての保証はありませんので、あくまで「冒険のちょっとしたメモ帳・参考ガイド」として気楽にご活用ください！
- 保存されるワールド・座標・攻略進捗データは **IndexedDB**、テーマや表示設定は **localStorage** にお使いのブラウザ内で永続保存されます（サーバーへの送信は一切ありません）。大切なデータはアプリ内のJSONバックアップ機能で適宜保存しておくのがおすすめです。

## 主な機能

- **インタラクティブ座標マップ**
  - オーバーワールド（地上）・ネザー・ジ・エンドの3ディメンション切り替えに対応
  - チャンク / リージョングリッド表示、ピンチ＆マウスホイールでのスムーズな拡大縮小
  - 現在位置を確認できるミニマップ・全体表示ジャンプボタン・画面外ピンへの誘導機能
  - 地図上のタップ／クリック位置からのクイック地点登録
- **地点（ウェイポイント）の登録・管理**
  - 初期スポーン、ベッド、拠点、村、ネザーゲート、要塞、海底神殿などを絵文字＆カラー付きで管理
  - 「現在のプレイヤー座標を自動入力」や、F3画面・`/tp` コマンド文字列のスマート貼り付けに対応
  - 地上 ↔ ネザーの `1:8` 座標換算および対応ネザーゲートの同時ペア登録
  - 左右スワイプによる地点カテゴリのタブ切り替え
- **直線距離・移動時間の計算**
  - 現在地（プレイヤー位置）から選択した地点までの直線距離と8方位を表示
  - 歩き・走り（ダッシュ）・走りジャンプでの移動目安時間を自動計算
- **サバイバル攻略ガイド（4タブ横スワイプ）**
  - **鉱石Y座標**: 主要鉱石の生成範囲・推奨高度・採掘ヒントをディメンション別に検索
  - **エンドラ討伐**: 初期スポーンから討伐までをチェックリスト形式で管理（ワールド別進捗保存）
  - **構造物**: 砂漠のピラミッド、沈没船、海底神殿、古代都市、トライアルチャンバー等の攻略ポイント
  - **イベント**: 襲撃イベント、ウィザー討伐、ピグリン交易などの準備と立ち回りチートシート
- **マルチワールド・バックアップ・PWA対応**
  - 複数ワールドの切り替え管理、JSON形式でのエクスポート／インポート
  - ライト／ダークテーマ切り替え
  - オフライン動作・ホーム画面へのインストール・自動アップデート対応

## 技術スタック

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Storage**: IndexedDB（ワールド・座標・進捗） / localStorage（表示設定・UI状態）
- **PWA**: `vite-plugin-pwa` (Workbox)

## ローカル開発・ビルド方法

```bash

# 開発サーバーの起動 (http://localhost:3000)
npm run dev

# 型チェック
npm run lint

# 本番用ビルド
npm run build
```

## GitHub Pages への公開方法（GitHub Actions）

このリポジトリには自動デプロイ用のワークフロー（`.github/workflows/deploy.yml`）が含まれています。

1. GitHub 上でリポジトリを作成し、このプロジェクトを `main`（または `master`）ブランチへ `git push` します（`.aistudio/` や `dev-dist/` は `.gitignore` により自動で除外されます）。
2. リポジトリの **Settings > Pages > Build and deployment > Source** を **「GitHub Actions」** に変更します。
3. 以降、`main` / `master` ブランチへ push するたびに自動でビルド＆GitHub Pages へ公開され、PWA としてスマホのホーム画面にもインストールできるようになります。
